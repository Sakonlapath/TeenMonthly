# เชื่อมคลังโค้ดรหัสกับ Supabase Free

> กด **เข้าสู่ระบบ** ด้านขวาบนเพื่อเปิดคลังโค้ดรหัสของบัญชี Supabase ใช้ Username `teen` กับ Password ที่ตั้งไว้ เมื่อล็อกอินจะแสดง Username และปุ่มออกจากระบบแทนข้อความบันทึกในเครื่อง เมนู **จัดการข้อมูล** ยังรวม Excel, JSON และซิงก์ข้ามเครื่องไว้เหมือนเดิม

## ทำไมอีกเครื่องไม่เห็นข้อมูลที่เพิ่ม

- การเพิ่ม/แก้ไขบันทึกลงในเบราว์เซอร์ของเครื่องนั้นก่อน ยังไม่ส่งขึ้น Supabase เอง เครื่องอื่น เบราว์เซอร์อื่น หรือการเปิดคนละ URL อาจมีข้อมูลในเครื่องคนละชุด
- การ push GitHub ส่งไฟล์โปรแกรม ไม่ได้ส่งข้อมูลใน localStorage ของผู้ใช้ไปด้วย
- Supabase รุ่นนี้แยกคลังตามบัญชีด้วย `owner_id` คนละบัญชีจึงมีข้อมูลคนละคลัง แม้จะใช้โปรเจกต์เดียวกัน
- หากเปิดคลังบัญชีเดิมจากอีกเครื่อง ต้องส่งข้อมูลจากเครื่องต้นทาง แล้วเข้าสู่ระบบบัญชีคลังนั้นในเครื่องปลายทางและกดโหลดข้อมูล
- ยังไม่มีคลังทีมที่ให้บัญชีนักพัฒนาและบัญชีผู้ใช้อีกคนดู/แก้คลังเดียวกัน การรองรับแบบนั้นต้องเพิ่มสมาชิกคลังและนโยบายสิทธิ์โดยเฉพาะ ไม่ควรปิด RLS เพื่อให้เห็นข้อมูลร่วมกัน

ป้ายด้านบนบอก **บันทึกเฉพาะเครื่องนี้** หรือสถานะบัญชี/ข้อมูลรอส่งไว้อย่างชัดเจน ก่อนโหลดทับข้อมูลในเครื่อง โปรแกรมจะให้ยืนยันและดาวน์โหลด JSON สำรอง ข้อมูลเดิมบนเครื่องแฟนจะไม่ย้ายมาบนเครื่องนักพัฒนาเพียงเพราะอัปเดตไฟล์โปรแกรม

## ค่าการเชื่อมต่อของโปรแกรมชุดนี้

ตั้งค่าเริ่มต้นเป็นโปรเจกต์ **ForTeenProject** แล้ว: `https://omtcyjoewqtfsreshgfu.supabase.co` พร้อม Publishable key ที่เจ้าของโปรเจกต์ให้มา ทั้ง `index.html` และ `ShiftPlanner-Standalone.html`

เปิดไฟล์โปรแกรมใหม่หรือรีเฟรช → **เข้าสู่ระบบ** ด้านขวาบน แล้วกรอก Username กับ Password โปรแกรมใช้ URL และ Publishable key ของโปรเจกต์นี้จากโค้ดโดยตรง ไม่มีส่วนตั้งค่าโปรเจกต์บนหน้าจอ และไม่อ่านค่าโปรเจกต์เก่าที่เคยบันทึกในเบราว์เซอร์

หลังเข้าสู่ระบบ โปรแกรมจะโหลดคลังออนไลน์อัตโนมัติถ้าแคชบัญชีไม่มีการแก้ไขค้างอยู่ หากมีรายการที่ยังไม่ได้ส่งจะเก็บรายการเดิมไว้และแจ้งให้เลือกส่งหรือสำรองแล้วโหลดข้อมูล คลังในเครื่องแยกต่างหากและไม่ถูกแทนที่ กด **รวมรหัสจากคลังในเครื่อง → ส่งข้อมูลขึ้นออนไลน์** เมื่อต้องการย้ายรายการเดิมเข้าบัญชี การเข้าสู่ระบบไม่ส่งข้อมูลขึ้นออนไลน์โดยอัตโนมัติ

เมนู **โค้ดรหัส** ใช้งานในเครื่องได้ทันที ไม่ต้องสมัครบริการใดก่อน เพิ่มหมวด A–Z ตามด้วยตัวเลข เช่น `A00` หรือ `A00.1` แล้วกรอกชื่อโรค เงื่อนไข หัตถการ และ Note ตามต้องการ ไม่มีข้อมูลโรคสำเร็จรูปติดตั้งมาให้

การเข้าสู่ระบบนี้เชื่อมเฉพาะคลังโค้ดรหัส ตารางเวรยังบันทึกในเครื่องและส่งออกได้แบบเดิม โปรแกรมอ่านข้อมูลออนไลน์เมื่อเข้าสู่ระบบ แต่การเพิ่ม แก้ไข และลบต้องกด **ส่งข้อมูลขึ้นออนไลน์** เอง ไม่มีการอัปเดตแบบเรียลไทม์

## 1. สร้างฐานข้อมูลฟรี

1. สมัครหรือเข้าสู่ระบบที่ [Supabase Dashboard](https://supabase.com/dashboard)
2. สร้าง Organization และ Project โดยเลือก **Free** ตั้งรหัสผ่านฐานข้อมูลและเลือกภูมิภาคที่เหมาะสม แล้วรอโปรเจกต์พร้อม
3. เปิด **SQL Editor → New query**
4. เปิดไฟล์ [`supabase/code-library.sql`](supabase/code-library.sql) ในโฟลเดอร์โปรแกรม คัดลอกเนื้อหาทั้งหมด วางใน SQL Editor แล้วกด **Run**
5. จะได้ตาราง `public.code_libraries` และฟังก์ชัน `save_code_library` พร้อมนโยบายให้ผู้ใช้ดูและแก้เฉพาะคลังของตน

ตาม [แพ็กเกจปัจจุบันของ Supabase](https://supabase.com/pricing) ที่ตรวจวันที่ 28 ตุลาคม 2026 Free มีฐานข้อมูล 500 MB ต่อโปรเจกต์ และอาจพักโปรเจกต์หลังไม่ใช้งานประมาณ 7 วัน หากพักให้กลับไปเปิดใน Dashboard ก่อนเชื่อมต่อ เงื่อนไขของบริการอาจเปลี่ยนได้ ไม่จำเป็นต้องอัปเกรดเป็นแผนเสียเงินเพื่อใช้ฟังก์ชันนี้

## 2. สร้างบัญชีสำหรับเข้าคลัง

หน้าโปรแกรมรับแค่ Username และ Password ไม่ต้องมีอีเมลจริง ระบบสร้างตัวระบุบัญชีภายในจาก Username กับชื่อโปรเจกต์ ไม่ส่งจดหมายยืนยันหรือรีเซ็ตรหัสผ่านจากหน้าโปรแกรม

ผู้พัฒนาต้องตั้งค่าบัญชีบนโปรเจกต์ครั้งเดียว:

1. เปิด [Authentication → Users ของโปรเจกต์นี้](https://supabase.com/dashboard/project/omtcyjoewqtfsreshgfu/auth/users) แล้วเลือก **Add user → Create new user**
2. ช่อง Email ของระบบหลังบ้าน ใส่ตัวระบุภายใน `teen@omtcyjoewqtfsreshgfu.supabase.co` ซึ่งไม่ใช่กล่องจดหมายจริงที่ผู้ใช้ต้องมี
3. ตั้ง Password ใหม่อย่างน้อย 6 ตัวอักษร เลือก **Auto Confirm User** แล้วสร้างบัญชี โดยไม่ต้องส่งรหัสผ่านให้ผู้พัฒนาหรือใส่ลงในไฟล์โปรแกรม
4. กลับเข้าโปรแกรมด้วย Username `teen` และ Password ที่เพิ่งตั้งไว้

โปรเจกต์นี้เปิดการยืนยันบัญชีอยู่ จึงต้องเลือก Auto Confirm ตอนสร้างบัญชี การเปลี่ยนหน้าโปรแกรมอย่างเดียวไม่ได้สร้างผู้ใช้ใน Supabase ให้อัตโนมัติ

ถ้ามีข้อมูลบนบัญชีเดิม ให้สำรอง JSON ไว้ก่อนสร้างบัญชีใหม่ แล้วนำเข้าขณะเปิดคลัง `teen` และกดส่งข้อมูลขึ้นออนไลน์ เพราะบัญชีใหม่มีรหัสเจ้าของคลังคนละตัว ข้อมูลเดิมจะไม่ย้ายตาม Username เอง

การตั้งบัญชีอ้างอิง [Supabase Admin createUser](https://supabase.com/docs/reference/javascript/auth-admin-createuser) ใช้ฝั่งผู้ดูแลเท่านั้น ห้ามใส่ service role key ลงในหน้าโปรแกรม

ในรุ่นนี้แต่ละบัญชีมีคลังของตนเอง ใช้บัญชีเดิมเพื่อเปิดคลังบนอุปกรณ์ส่วนตัวอีกเครื่อง การใช้คนละบัญชีไม่ได้ทำให้เห็นคลังร่วมกัน รุ่นนี้ยังไม่มีระบบทีม/สิทธิ์ผู้ร่วมแก้ไข

## 3. การเชื่อมต่อของโปรแกรม

ตั้งค่าโปรเจกต์ไว้ใน `js/code-library.js` แล้ว และรวมค่าเดียวกันไว้ในไฟล์ Standalone ผู้ใช้กรอกแค่ Username กับ Password ไม่ต้องตั้งค่า URL หรือคีย์บนหน้าโปรแกรม

ใช้คีย์สาธารณะเท่านั้น โปรแกรมปฏิเสธ secret และ service_role keys เพราะคีย์เหล่านี้ข้ามสิทธิ์ข้อมูลได้ ดู [คำอธิบาย API keys](https://supabase.com/docs/guides/getting-started/api-keys) และ [Row Level Security](https://supabase.com/docs/guides/database/postgres/row-level-security)

URL และคีย์สาธารณะอยู่ในไฟล์โปรแกรม รหัสผ่านและโทเคนเข้าสู่ระบบอยู่ในหน่วยความจำระหว่างเปิดหน้าเท่านั้น เมื่อรีเฟรชต้องเข้าสู่ระบบใหม่ ข้อมูลคลังที่โหลดไว้ยังอยู่ในเครื่องและแก้ไขออฟไลน์ได้

## 4. นำรายการในเครื่องขึ้นออนไลน์ครั้งแรก

1. เพิ่มรายการในเมนู **โค้ดรหัส** ได้ตามปกติ
2. แนะนำกด **จัดการข้อมูล → สำรอง JSON** เก็บไว้ก่อน
3. เข้าสู่ระบบ Supabase ตามขั้นตอนข้างต้น โปรแกรมจะเปิดคลังแคชแยกสำหรับบัญชีนั้น คลังในเครื่องเดิมยังอยู่
4. ถ้าบัญชีเคยมีข้อมูลออนไลน์แล้ว ให้กด **โหลดข้อมูลจากออนไลน์** ก่อน
5. กด **รวมรหัสจากคลังในเครื่อง** แล้วกด **ส่งข้อมูลขึ้นออนไลน์**
6. รอข้อความส่งสำเร็จพร้อมเลขรุ่นข้อมูล

รหัสและเลขเดียวกันเก็บได้หลายรายการ แต่ละรายการมีตัวระบุแยกกันเพื่อแก้ไขและลบเฉพาะแถวที่เลือก การรวมเพิ่มรายการใหม่โดยรักษารายการเดิมไว้ และนำเข้าไฟล์สำรองเดิมซ้ำได้โดยไม่เพิ่มแถวเดิมซ้ำอีก หากเป็นรายการเดิมตัวระบุเดียวกันแต่รายละเอียดต่างกัน ระบบจะหยุดให้ตรวจสอบก่อน ข้อมูลและ JSON รุ่นเก่าจะเพิ่มตัวระบุให้อัตโนมัติเมื่อเปิดใช้

## 5. ใช้งานอีกเครื่องและแก้ไขออฟไลน์

1. เปิดโปรแกรมบนอีกเครื่อง ใส่ URL และคีย์ของโปรเจกต์เดิมแล้วเข้าสู่ระบบบัญชีเดิม
2. กด **โหลดข้อมูลจากออนไลน์** เพื่อเริ่มจากรุ่นล่าสุด ก่อนแก้ไขในเครื่องนั้น
3. เพิ่ม แก้ไข หรือลบรหัสได้แม้ไม่มีอินเทอร์เน็ต การแก้ไขถูกเก็บในแคชบัญชีบนเบราว์เซอร์นั้น
4. เมื่อมีอินเทอร์เน็ต เข้าสู่ระบบแล้วกด **ส่งข้อมูลขึ้นออนไลน์**
5. เครื่องอื่นต้องกดโหลดใหม่จึงจะเห็นการแก้ไข ไม่มีการอัปเดตแบบเรียลไทม์

คลังในเครื่องและแคชแต่ละบัญชีเก็บแยกกัน เมื่อกด **ออกจากระบบ** โปรแกรมจะกลับไปคลังในเครื่องโดยเก็บแคชบัญชีไว้ ไม่ออกจากระบบบนอุปกรณ์อื่น อ้างอิง [Supabase sign-out scopes](https://supabase.com/docs/guides/auth/signout) ข้อมูลที่แคชในเบราว์เซอร์ไม่ได้เข้ารหัสด้วยรหัสผ่าน ผู้ใช้เครื่องเดียวกันยังเข้าถึงข้อมูลที่เก็บไว้บนเครื่องได้

### เมื่อสองเครื่องแก้พร้อมกัน

การบันทึกตรวจเลขรุ่นแบบ atomic หากอีกเครื่องส่งข้อมูลก่อน ระบบจะหยุดโดยเก็บข้อมูลของเครื่องปัจจุบันไว้

1. สำรอง JSON ของเครื่องปัจจุบันไว้ก่อน
2. กด **โหลดข้อมูลจากออนไลน์** ระบบจะดาวน์โหลดไฟล์สำรองปัจจุบันอีกครั้งก่อนแทนที่ ตรวจว่าเบราว์เซอร์ดาวน์โหลดไฟล์สำเร็จ
3. นำเข้า JSON ที่สำรองเพื่อรวมรายการใหม่ หากรายการตัวระบุเดียวกันมีรายละเอียดต่างกัน ให้เปิดไฟล์สำรองเปรียบเทียบและแก้รายการนั้นด้วยตนเองก่อนรวม รายการคนละตัวระบุที่ใช้รหัสเดียวกันเก็บร่วมกันได้
4. กดส่งขึ้นออนไลน์อีกครั้ง

การส่งทั้งคลังรวมการลบรายการด้วย จึงควรโหลดรุ่นล่าสุดก่อนเริ่มทำงานจากอีกเครื่อง

## ส่งออก Excel และสำรอง

- **Excel ทุกรหัส (.xlsx)** ส่งทั้งคลัง แยกคอลัมน์หมวด รหัส ชื่อโรค เงื่อนไข หัตถการ และ Note
- **Excel เฉพาะผลค้นหา** ใช้หมวด คำค้น และตัวกรองที่กำลังเลือก รวมทุกหน้าของผลค้นหา
- **สำรองคลังรหัส JSON** ใช้นำกลับมาแก้ไขหรือย้ายเครื่องได้ ไฟล์นี้แยกจาก JSON สำรองตารางเวร
- **นำเข้า / รวม JSON** รับเฉพาะไฟล์สำรองคลังรหัส ไม่รองรับนำเข้า Excel ในรุ่นนี้

คลังรองรับไม่เกิน 10,000 รหัส และข้อมูลรวมประมาณ 4.5 MB ต่อบัญชี ซึ่งเหมาะสำหรับคลังอ้างอิงส่วนตัว ตรวจสอบข้อความบันทึกในเครื่องเสมอ เพราะเบราว์เซอร์มีโควตา localStorage ร่วมกับข้อมูลตารางเวร เมื่อบันทึกในเครื่องไม่ได้ โปรแกรมจะแจ้งและให้สำรอง JSON ก่อนปิดหน้า

## แก้ปัญหาการเชื่อมต่อ

- **ยังไม่พบตารางหรือฟังก์ชัน**: รัน SQL ให้ครบในโปรเจกต์เดียวกับ URL ที่กรอก
- **เข้าสู่ระบบไม่ได้**: ตรวจว่าตั้งบัญชีภายในตามขั้นตอนที่ 2 แล้ว ตรวจ Username, Password และ Auto Confirm ของบัญชี
- **เชื่อมต่อไม่ได้**: ตรวจอินเทอร์เน็ต URL และโปรเจกต์พักหรือไม่ หากเบราว์เซอร์จำกัดคำขอจาก `file://` ให้เปิดโฟลเดอร์ด้วย VS Code Live Server แล้วใช้ `index.html`
- **คลังถูกแก้จากอีกแท็บ**: สำรอง JSON ของแท็บปัจจุบันแล้วรีเฟรช ก่อนนำเข้ารวมและทำงานต่อ
- **ข้อมูลแคชเสียหาย**: เมนูส่งออกมีปุ่มดาวน์โหลดข้อมูลเดิมและเริ่มคลังใหม่ เก็บไฟล์กู้คืนไว้ก่อนใช้งานต่อ

ทดสอบจริงหลังตั้งค่าด้วยการเพิ่มรหัส ส่งขึ้นออนไลน์ แล้วเปิดอีกเบราว์เซอร์ด้วยบัญชีเดิมและโหลดมา ขณะพัฒนาได้ทดสอบผ่านคำขอจำลองแล้ว การยืนยันการเชื่อมโปรเจกต์จริงต้องใช้โปรเจกต์และผู้ใช้ที่คุณสร้าง
