# เชื่อมคลังโค้ดรหัสกับ Supabase Free

> รุ่นธีมคิตตี้เอาปุ่มฐานข้อมูลออนไลน์ออกจากหน้าผู้ใช้แล้ว เมนู **จัดการข้อมูล** รวม Excel และ JSON ไว้ด้วยกัน ส่วนโมดูล Supabase และแคชเดิมยังเก็บไว้สำหรับผู้พัฒนา หากต้องตั้งค่าเพิ่มเติม ผู้พัฒนาเรียก `CodeLibrary.cloud()` ผ่าน Developer Console ได้ คู่มือการเชื่อมด้านล่างใช้กับหน้าต่างนั้น

## ค่าการเชื่อมต่อของโปรแกรมชุดนี้

ตั้งค่าเริ่มต้นเป็นโปรเจกต์ **ForTeenProject** แล้ว: `https://omtcyjoewqtfsreshgfu.supabase.co` พร้อม Publishable key ที่เจ้าของโปรเจกต์ให้มา ทั้ง `index.html` และ `ShiftPlanner-Standalone.html`

เปิดไฟล์โปรแกรมใหม่หรือรีเฟรช → **โค้ดรหัส → ฐานข้อมูลออนไลน์** ช่อง Project URL และ Publishable key จะมีค่าให้แล้ว กรอกอีเมลและรหัสผ่านของผู้ใช้ที่สร้างใน Authentication แล้วเข้าสู่ระบบ หากเคยบันทึกค่าโปรเจกต์อื่นไว้ เบราว์เซอร์จะใช้ค่าที่บันทึกไว้ก่อน ให้เปลี่ยนกลับมาเป็นโปรเจกต์นี้ในหน้าต่างเชื่อมต่อ

หลังเข้าสู่ระบบครั้งแรก กด **รวมรหัสจากคลังในเครื่อง → ส่งข้อมูลขึ้นออนไลน์** หากบัญชีนี้มีข้อมูลออนไลน์อยู่แล้ว ให้โหลดข้อมูลจากออนไลน์ก่อนรวมรายการ การตั้งค่า URL และคีย์ยังไม่ใช่การเข้าสู่ระบบ และไม่ส่งข้อมูลขึ้นออนไลน์โดยอัตโนมัติ

เมนู **โค้ดรหัส** ใช้งานในเครื่องได้ทันที ไม่ต้องสมัครบริการใดก่อน เพิ่มหมวด A–Z ตามด้วยตัวเลข เช่น `A00` หรือ `A00.1` แล้วกรอกชื่อโรค เงื่อนไข หัตถการ และ Note ตามต้องการ ไม่มีข้อมูลโรคสำเร็จรูปติดตั้งมาให้

การเชื่อมออนไลน์นี้เก็บเฉพาะคลังโค้ดรหัส ตารางเวรและไฟล์ Excel ตารางเวรยังทำงานแบบเดิม การส่งขึ้นออนไลน์เป็นการกดด้วยตัวเอง ไม่ซิงก์อัตโนมัติ

## 1. สร้างฐานข้อมูลฟรี

1. สมัครหรือเข้าสู่ระบบที่ [Supabase Dashboard](https://supabase.com/dashboard)
2. สร้าง Organization และ Project โดยเลือก **Free** ตั้งรหัสผ่านฐานข้อมูลและเลือกภูมิภาคที่เหมาะสม แล้วรอโปรเจกต์พร้อม
3. เปิด **SQL Editor → New query**
4. เปิดไฟล์ [`supabase/code-library.sql`](supabase/code-library.sql) ในโฟลเดอร์โปรแกรม คัดลอกเนื้อหาทั้งหมด วางใน SQL Editor แล้วกด **Run**
5. จะได้ตาราง `public.code_libraries` และฟังก์ชัน `save_code_library` พร้อมนโยบายให้ผู้ใช้ดูและแก้เฉพาะคลังของตน

ตาม [แพ็กเกจปัจจุบันของ Supabase](https://supabase.com/pricing) ที่ตรวจวันที่ 28 ตุลาคม 2026 Free มีฐานข้อมูล 500 MB ต่อโปรเจกต์ และอาจพักโปรเจกต์หลังไม่ใช้งานประมาณ 7 วัน หากพักให้กลับไปเปิดใน Dashboard ก่อนเชื่อมต่อ เงื่อนไขของบริการอาจเปลี่ยนได้ ไม่จำเป็นต้องอัปเกรดเป็นแผนเสียเงินเพื่อใช้ฟังก์ชันนี้

## 2. สร้างบัญชีสำหรับเข้าคลัง

1. ที่ Supabase เปิด **Authentication → Users → Add user → Create new user**
2. ใส่อีเมลและรหัสผ่านสำหรับใช้กับโปรแกรม เลือก **Auto Confirm User / ยืนยันอีเมล** แล้วสร้างผู้ใช้
3. ถ้าไม่ได้ยืนยันอีเมล ต้องยืนยันก่อนจึงจะเข้าสู่ระบบได้
4. รหัสผ่านที่ใช้ในโปรแกรมคือรหัสผ่านของผู้ใช้นี้ ไม่ใช่รหัสผ่านฐานข้อมูลหรือบัญชี Dashboard

ในรุ่นนี้แต่ละบัญชีมีคลังของตนเอง ใช้บัญชีเดิมเพื่อเปิดคลังบนอุปกรณ์ส่วนตัวอีกเครื่อง การใช้คนละบัญชีไม่ได้ทำให้เห็นคลังร่วมกัน รุ่นนี้ยังไม่มีระบบทีม/สิทธิ์ผู้ร่วมแก้ไข

## 3. ใส่ค่าการเชื่อมต่อในโปรแกรม

1. ที่ Supabase เปิด **Connect** เพื่อหา **Project URL** รูปแบบ `https://ชื่อโปรเจกต์.supabase.co`
2. คัดลอก **Publishable key** จาก **Settings → API Keys** โดยทั่วไปขึ้นต้น `sb_publishable_…` หรือใช้ legacy `anon` key ได้
3. เปิด `ShiftPlanner-Standalone.html` หรือ `index.html` → **โค้ดรหัส → ฐานข้อมูลออนไลน์**
4. ใส่ URL, Publishable key, อีเมล และรหัสผ่านผู้ใช้ แล้วกด **เข้าสู่ระบบ**

ใช้คีย์สาธารณะเท่านั้น โปรแกรมปฏิเสธ secret และ service_role keys เพราะคีย์เหล่านี้ข้ามสิทธิ์ข้อมูลได้ ดู [คำอธิบาย API keys](https://supabase.com/docs/guides/getting-started/api-keys) และ [Row Level Security](https://supabase.com/docs/guides/database/postgres/row-level-security)

URL และคีย์สาธารณะถูกจำในเบราว์เซอร์ รหัสผ่านและโทเคนเข้าสู่ระบบอยู่ในหน่วยความจำระหว่างเปิดหน้าเท่านั้น เมื่อรีเฟรชต้องเข้าสู่ระบบใหม่ ข้อมูลคลังที่โหลดไว้ยังอยู่ในเครื่องและแก้ไขออฟไลน์ได้

## 4. นำรายการในเครื่องขึ้นออนไลน์ครั้งแรก

1. เพิ่มรายการในเมนู **โค้ดรหัส** ได้ตามปกติ
2. แนะนำกด **ส่งออก / สำรอง → สำรองคลังรหัส JSON** เก็บไว้ก่อน
3. เข้าสู่ระบบ Supabase ตามขั้นตอนข้างต้น โปรแกรมจะเปิดคลังแคชแยกสำหรับบัญชีนั้น คลังในเครื่องเดิมยังอยู่
4. ถ้าบัญชีเคยมีข้อมูลออนไลน์แล้ว ให้กด **โหลดข้อมูลจากออนไลน์** ก่อน
5. กด **รวมรหัสจากคลังในเครื่อง** แล้วกด **ส่งข้อมูลขึ้นออนไลน์**
6. รอข้อความส่งสำเร็จพร้อมเลขรุ่นข้อมูล

การรวมจะเก็บรหัสใหม่ เพิ่มเติมจากรหัสที่มี หากรหัสเดียวกันมีรายละเอียดต่างกัน ระบบจะหยุดทั้งการนำเข้าเพื่อให้ตรวจแก้ก่อน จึงไม่เขียนทับรายละเอียดเดิมโดยอัตโนมัติ

## 5. ใช้งานอีกเครื่องและแก้ไขออฟไลน์

1. เปิดโปรแกรมบนอีกเครื่อง ใส่ URL และคีย์ของโปรเจกต์เดิมแล้วเข้าสู่ระบบบัญชีเดิม
2. กด **โหลดข้อมูลจากออนไลน์** เพื่อเริ่มจากรุ่นล่าสุด ก่อนแก้ไขในเครื่องนั้น
3. เพิ่ม แก้ไข หรือลบรหัสได้แม้ไม่มีอินเทอร์เน็ต การแก้ไขถูกเก็บในแคชบัญชีบนเบราว์เซอร์นั้น
4. เมื่อมีอินเทอร์เน็ต เข้าสู่ระบบแล้วกด **ส่งข้อมูลขึ้นออนไลน์**
5. เครื่องอื่นต้องกดโหลดใหม่จึงจะเห็นการแก้ไข ไม่มีการอัปเดตแบบเรียลไทม์

คลังในเครื่องและแคชแต่ละบัญชีเก็บแยกกัน กด **เปิดคลังในเครื่อง** เพื่อกลับไปดูคลังเริ่มต้น การออกจากระบบไม่ได้ลบแคชที่เก็บไว้บนเครื่อง ดังนั้นผู้ใช้เครื่องเดียวกันยังเปิดแคชได้

### เมื่อสองเครื่องแก้พร้อมกัน

การบันทึกตรวจเลขรุ่นแบบ atomic หากอีกเครื่องส่งข้อมูลก่อน ระบบจะหยุดโดยเก็บข้อมูลของเครื่องปัจจุบันไว้

1. สำรอง JSON ของเครื่องปัจจุบันไว้ก่อน
2. กด **โหลดข้อมูลจากออนไลน์** ระบบจะดาวน์โหลดไฟล์สำรองปัจจุบันอีกครั้งก่อนแทนที่ ตรวจว่าเบราว์เซอร์ดาวน์โหลดไฟล์สำเร็จ
3. นำเข้า JSON ที่สำรองเพื่อรวมรายการใหม่ หากรหัสเดิมมีรายละเอียดต่างกัน ให้เปิดไฟล์สำรองเปรียบเทียบและแก้ไขรหัสนั้นด้วยตนเองก่อนรวม
4. กดส่งขึ้นออนไลน์อีกครั้ง

การส่งทั้งคลังรวมการลบรายการด้วย จึงควรโหลดรุ่นล่าสุดก่อนเริ่มทำงานจากอีกเครื่อง

## ส่งออก Excel และสำรอง

- **Excel ทุกรหัส (.xlsx)** ส่งทั้งคลัง แยกคอลัมน์หมวด รหัส ชื่อโรค เงื่อนไข หัตถการ และ Note
- **Excel เฉพาะผลค้นหา** ใช้หมวด คำค้น และตัวกรองที่กำลังเลือก รวมทุกหน้าของผลค้นหา
- **สำรองคลังรหัส JSON** ใช้นำกลับมาแก้ไขหรือย้ายเครื่องได้ ไฟล์นี้แยกจาก JSON สำรองตารางเวร
- **นำเข้า / รวม JSON** รับเฉพาะไฟล์สำรองคลังรหัส ไม่รองรับนำเข้า Excel ในรุ่นนี้

คลังรองรับไม่เกิน 10,000 รหัส และข้อมูลรวมประมาณ 4.5 MB ต่อบัญชี ซึ่งเหมาะสำหรับคลังอ้างอิงส่วนตัว ตรวจสอบข้อความบันทึกในเครื่องเสมอ เพราะเบราว์เซอร์มีโควตา localStorage ร่วมกับข้อมูลตารางเวร เมื่อบันทึกในเครื่องไม่ได้ โปรแกรมจะแจ้งและให้สำรอง JSON ก่อนปิดหน้า

## แก้ปัญหาการเชื่อมต่อ

- **ยังไม่พบตารางหรือฟังก์ชัน**: รัน SQL ให้ครบในโปรเจกต์เดียวกับ URL ที่กรอก
- **เข้าสู่ระบบไม่ได้**: ตรวจผู้ใช้ใน Authentication, รหัสผ่าน และสถานะยืนยันอีเมล
- **เชื่อมต่อไม่ได้**: ตรวจอินเทอร์เน็ต URL และโปรเจกต์พักหรือไม่ หากเบราว์เซอร์จำกัดคำขอจาก `file://` ให้เปิดโฟลเดอร์ด้วย VS Code Live Server แล้วใช้ `index.html`
- **คลังถูกแก้จากอีกแท็บ**: สำรอง JSON ของแท็บปัจจุบันแล้วรีเฟรช ก่อนนำเข้ารวมและทำงานต่อ
- **ข้อมูลแคชเสียหาย**: เมนูส่งออกมีปุ่มดาวน์โหลดข้อมูลเดิมและเริ่มคลังใหม่ เก็บไฟล์กู้คืนไว้ก่อนใช้งานต่อ

ทดสอบจริงหลังตั้งค่าด้วยการเพิ่มรหัส ส่งขึ้นออนไลน์ แล้วเปิดอีกเบราว์เซอร์ด้วยบัญชีเดิมและโหลดมา ขณะพัฒนาได้ทดสอบผ่านคำขอจำลองแล้ว การยืนยันการเชื่อมโปรเจกต์จริงต้องใช้โปรเจกต์และผู้ใช้ที่คุณสร้าง
