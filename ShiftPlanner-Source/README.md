# เว็บจัดเวรห้องบัตร

## เปิดใช้งาน
1. แตกไฟล์ ZIP ให้ครบทั้งโฟลเดอร์
2. ใน VS Code เลือก File > Open Folder แล้วเลือกโฟลเดอร์นี้
3. เปิด index.html ด้วย Chrome หรือใช้ Live Server ใน VS Code

ไม่ต้อง npm install และไม่ต้อง build ไฟล์ ไม่มีไลบรารีจากภายนอก

## ไฟล์ที่แก้ไขได้
- index.html: โครงสร้างหน้าเว็บ
- css/styles.css: สี ขนาดตัวอักษร การจัดวาง และรูปแบบตอนพิมพ์
- js/core.js: กติกาเวร ตัวตรวจเงื่อนไข และตัวจัดอัตโนมัติ
- js/data.js: รายชื่อและการตั้งค่าเริ่มต้น โดยทุกเดือนเริ่มด้วยตารางว่าง
- js/app.js: การคลิกตาราง หน้าต่างแก้ไข สรุปเวร บันทึกและส่งออก
- tests/engine.test.cjs: ตรวจเงื่อนไขของตัวจัดเวร
- ShiftPlanner-Standalone.html: เวอร์ชันรวมทุกอย่างในไฟล์เดียว เปิดได้ทันที

## วิธีใช้งาน
- เมนู “แชท” ใช้ลงวันออก รพ.สต.: กด “เลือกวันออก รพ.สต.” เลือกเดือน แล้วตอบ “วันที่เท่าไหร่บ้างคะ” เช่น `3, 5-6` ระบบเพิ่มเวร รพ.สต. วันที่ 3, 5, 6 วันละอย่างน้อย 1 คน พร้อมป้ายที่หัววันที่ และเปิดตารางเดือนนั้นให้ทันที
- แชททักทายว่า “สวัสดีค่ะ วันนี้มีอะไรให้ช่วยคะ” และมีปุ่ม “วันห้องบัตร (ร)” สำหรับเพิ่มวันเปิดเวร ร สีฟ้า โดยเลือกเดือนแล้วพิมพ์วัน เช่น `1, 7-8` ระบบเก็บวันเดิมและจำนวนคนที่ตั้งไว้แล้ว
- ปุ่ม “OFF” และ “Vac” ถามตามลำดับ บุคลากร → เดือน → วันที่ ระบบตรวจว่าคนนั้นลงตารางเดือนที่เลือกก่อนรับวันที่ แล้วบันทึกวันหยุดหรือ VAC เฉพาะคนที่เลือก โดยเปลี่ยนเวรในวันที่เลือกเป็นวันหยุด ย้อนกลับทั้งชุดได้ในครั้งเดียว
- แชทรองรับเลขไทย ช่วงวันที่ และชื่อเดือน เช่น `ออก รพ.สต. ๓, ๕–๖ พฤศจิกา` โดยชื่อเดือน/ปีต้องตรงกับเดือนที่เลือก วันที่เกินเดือนหรือรูปแบบผิดจะไม่แก้ข้อมูล วันออกเดิมและจำนวนที่ตั้งเกิน 1 คนยังเก็บไว้ กดจัดเวรอัตโนมัติเมื่อต้องการจัดบุคลากรลงเวร
- แชทบันทึกวันทั้งชุดเป็นการแก้ไขครั้งเดียว จึงย้อนกลับได้ในครั้งเดียว ปิดแชทก่อนส่งวันจะไม่แก้ตาราง มีปุ่ม “เริ่มคุยใหม่” และเก็บบทสนทนาระหว่างเปิด–ปิดแชทจนกว่าจะรีเฟรชหน้า
- แถบสีเหนือตาราง: เลือกชนิดเวรแล้วคลิกหรือลากวันที่ในแถวของคนเดียวกัน ปล่อยเมาส์เพื่อบันทึกทั้งชุด หากผิดเงื่อนไขจะไม่แก้ไขทั้งชุด
- คีย์ 1–5 = ดึก / เช้า / บ่าย / ห้องบัตร / รพ.สต. · 6 = OFF · 7 = VAC · 0 = ยางลบ
- ใช้ Tab เข้าตาราง แล้วใช้ลูกศรเลื่อนช่อง; Shift + ลูกศรซ้าย/ขวาเลือกหลายวัน; Enter หรือ Space ใส่เวรที่เลือก; Delete ลบ; E เปิดรายละเอียด/ปลดล็อก
- Ctrl+Z (Mac: Cmd+Z) ย้อนทั้งชุดที่ลาก · Esc ยกเลิกก่อนบันทึก · คีย์ลัดหยุดทำงานในช่องกรอกข้อมูลและหน้าต่างแก้ไข
- บนจอสัมผัส: เลือกเวรก่อนลากเพื่อระบาย เปลี่ยนเป็นโหมด “ดู / แก้รายช่อง” เมื่อต้องการเลื่อนตาราง
- ปุ่ม “สร้างเอกสาร” ข้างปฏิทินรวม Excel ตามต้นฉบับ, CSV, พิมพ์/PDF, สำรอง JSON และนำเข้าไฟล์ไว้ในที่เดียว โดย Excel เก็บสี เส้นตาราง ฟอนต์ และเซลล์รวม ส่วน CSV เก็บเฉพาะข้อมูล
- เลือกเดือนแล้วเปิด “บุคลากร” ติ๊ก “ลงตารางเดือนนี้” เพื่อเลือกผู้ร่วมตาราง คนที่ไม่เลือกจะไม่แสดงในตาราง สรุปเงิน การจัดอัตโนมัติ และเอกสารของเดือนนั้น ข้อมูลเวรและเป้าเดิมยังเก็บไว้เมื่อเลือกกลับมา และไม่กระทบการเลือกของเดือนอื่น
- คลิกช่องบุคลากร/วันที่ เพื่อเลือกเวร OFF หรือ VAC
- เมื่อเลือกเวรเองและล็อกไว้ (◆) ระบบจะคงตารางทั้งเดือนของคนนี้ รวมช่องว่าง และจัดเฉพาะคนที่เหลือ โดยนับเวรที่คงไว้ในจำนวนคนต่อวันและเงื่อนไขเวรเท่ากัน
- หากต้องการให้ระบบจัดคนนี้อีกครั้ง ให้ปลดล็อกเวรทุกช่องของคนนี้ในเดือนนั้น · OFF / VAC เพียงอย่างเดียวกันเฉพาะวัน ไม่กันทั้งคน
- คลิกหัววันที่เพื่อกำหนดวันหยุดราชการและจำนวนคนของแต่ละเวร
- เลือกเดือนใหม่เพื่อเริ่มตารางว่าง เพิ่มวันหยุดราชการเอง
- กดจัดเวรอัตโนมัติ แล้วตรวจให้แสดงว่าผ่านทุกเงื่อนไขก่อนนำไปใช้
- ส่งออก CSV เพื่อเปิดใน Excel หรือพิมพ์/บันทึกเป็น PDF
- สำรอง JSON เพื่อย้ายเครื่องหรือเก็บข้อมูลไว้แก้ไขต่อ

## กติกาเริ่มต้น
- ร สีฟ้า ห้องบัตร: 06:30–08:30 ทุก จ.–ศ. วันละ 1 คน รวมวันที่ตรงวันหยุดราชการ ปรับได้ที่หัววันที่
- ร สีแดง รพ.สต.: 06:30–08:30 กำหนดจำนวนตามวันที่ออก
- วันหยุดและเสาร์–อาทิตย์: ดึก 1 เช้า 2 บ่าย 1 คน
- วันธรรมดา: ดึก 1 บ่าย 1 คน ตามไฟล์ตัวอย่าง ปรับได้ที่หัววันที่
- ดึก 00:00–08:00 / เช้า 08:00–16:00 / บ่าย 16:00–00:00
- คนลำดับ 2–4 ที่เลือกลงตารางในเดือนนั้นต้องมีเวรรวมเท่ากัน นับทุกประเภทครั้งละ 1 เวร ไม่ใช่ชั่วโมง ยึดลำดับบุคลากรเดิม ไม่เลื่อนกลุ่มเมื่อเอาคนออก
- กันวัน OFF และ VAC ออกจากการจัดอัตโนมัติ
- หนึ่งคนรับเวรได้วันละหนึ่งประเภท และห้ามบ่ายแล้วต่อดึก รุ่งอรุณห้องบัตร หรือ รพ.สต. ในวันถัดไป
- เวรดึกวัน จ.–ศ. รวมวันหยุดที่ตรง จ.–ศ. รับได้เฉพาะสุขสันต์ นุ่มนวล เกศสรา และปฏิภาณ โดยอ้างอิงรหัสบุคลากรเดิม 2–5
- ตรวจบ่ายต่อดึกและบ่ายต่อ ร ทั้งสองสีข้ามเดือนจากตารางเดือนข้างเคียงที่มีอยู่โดยอัตโนมัติ ไม่ต้องกรอกเวรก่อน/หลังเดือนในเมนูบุคลากร
- การเลือกเวรเองเป็นฉบับร่างได้ แอปเตือนจำนวนคนและความเท่ากันจนกว่าจะแก้ครบ
- ถ้าจัดไม่ได้ ระบบเก็บข้อมูลเดิมและแจ้งสาเหตุ

## เป้าหมายเวรและค่าเวร
- กรอกเฉพาะตัวเลขแยก 3 ช่องในตารางเวรและหน้าสรุป: ห้องบัตร (N/M/A), รุ่งอรุณ (R สีฟ้า), รพ.สต. (X สีแดง) แต่ละช่องเว้นว่างให้ระบบคำนวณได้ และ 0 หมายถึงไม่รับเวรประเภทนั้น ไม่มีเลขจัดแล้ว เครื่องหมาย / ข้อความ Auto หรือเป้ารวมใต้ช่อง
- เป้าทั้ง 3 ช่องของแต่ละคนรวมกันต้องไม่เกินจำนวนวันของเดือน ช่องของคนลำดับ 2–4 ใช้พื้นสีเขียวอ่อนเหมือนกัน กรอกหรือล้างคนใดคนหนึ่งแล้วอีกสองคนจะเปลี่ยนตามเฉพาะประเภทนั้น ทั้งในตารางเวรและหน้าสรุป
- ไฟล์สำรองเก่าที่ยังมีเป้ารวมช่องเดียวจะเก็บเป้าเดิมไว้จนกว่าจะเริ่มแก้เป้าแยกประเภท เมื่อจัดสำเร็จจะเติมเป้าแยกประเภทที่เว้นว่างจากผลที่จัดได้
- เมนูหลักอยู่ใน Header ด้านบนและตรึงไว้ตลอดเมื่อเลื่อนหน้า ทั้งบนคอมพิวเตอร์และมือถือ
- ยอดรวมที่กรอก ห้องบัตร / รุ่งอรุณ / รพ.สต. อยู่ในแถบสีอ่อนใต้เมนู พร้อมชื่อเดือนที่เลือก ตรึงอยู่ด้านบนทั้งเมื่อเลื่อนหน้าและเลื่อนตาราง ตัวเลขอัปเดตทันทีขณะพิมพ์ ไม่มีช่องยอดรวมท้ายตารางเวร
- “จำนวนเวรทั้งหมด” อยู่ใน Header เดียวกับยอด ห้องบัตร / รุ่งอรุณ / รพ.สต. และ “รายการที่ต้องตรวจ” ซึ่งกดเพื่อเปิดรายละเอียดเงื่อนไขได้ ไม่มีกล่องสรุปหรือแถบแจ้งเตือนขนาดใหญ่เหนือปฏิทิน
- “จำนวนเวรทั้งหมด” แสดงจำนวนจัดแล้วเทียบกับจำนวนที่กรอกทุกคน เมื่อกรอกครบทุกคน ระบบยึดยอดรวมนี้ในการจัด เช่น 9+15+15+15+5+5+6+8 = 78 เวร และปรับจำนวนรายวันตามผลที่จัดได้ ไม่บังคับให้ครบยอดเริ่มต้น 99 อีกชุดหนึ่ง
- ปุ่มจัดเวรอัตโนมัติอยู่ในหัวตารางข้าง “ล้างเวร” ช่องที่เว้นว่างให้ระบบคำนวณจะเติมจำนวนที่จัดได้หลังจัดสำเร็จ
- ระบบกระจายเวรลงในชนิดและวันที่เปิดรับไว้ โดยคง OFF/VAC เวรล็อกและข้อห้ามต่าง ๆ หากยอดที่กรอกมากกว่าช่องที่เปิดรับทั้งหมด จะแจ้งให้เพิ่มช่องเวรที่หัววันที่ การจัดตามยอดที่น้อยลงจะจำช่องที่เปิดรับเดิมไว้ จึงเพิ่มยอดแล้วจัดใหม่ได้
- นับ N / M / A / R / X เป็นครั้งละหนึ่งเวร ไม่รวม OFF / VAC หากลงเองไม่ครบหรือเกินเป้าจะแสดงเตือน คนที่มีเวรล็อกจะไม่ถูกเติมอัตโนมัติจนกว่าจะปลดล็อกทุกเวรของคนนั้น
- พฤกษา (id 1) กับรพีพรรณ (id 8) ห้ามขึ้นเวรวันเดียวกัน ทั้งการจัดเองและอัตโนมัติ
- R แบ่งเท่า ๆ กันในกลุ่มคนที่รับ R ได้ แล้วแจกเศษให้ลำดับ 1–4 ก่อน ไม่รวม X หากติดเวรล็อก โควตา วันหยุด หรือข้อจำกัดอื่น ระบบจะหาการกระจายที่ทำได้โดยรักษาข้อจำกัดเหล่านั้น
- เรทแยกต่อคนเป็น ห้องบัตร (N/M/A), รุ่งอรุณ (R), รพ.สต. (X) แก้ได้ในเมนูบุคลากร เป็นบาทต่อเวร ทศนิยมไม่เกิน 2 ตำแหน่ง เรทใช้กับทุกเดือน ยอดเงิน = จำนวนแต่ละประเภท × เรทประเภทนั้น ไม่รวม OFF/VAC
- ข้อมูลเก่าที่ยังเก็บเรทเป็นเลขเดียวจะใช้เรทเดิมกับทั้ง 3 ประเภทจนกว่าจะปรับ: พฤกษา 520; สุขสันต์/นุ่มนวล/เกศสรา 330; ปฏิภาณ/ขณัฏฐา/ธัชวดี 650; รพีพรรณ 390 บาท
- บุคลากรลำดับ 9 นายปรเมศวร์ ศิริเสาร์ ตำแหน่ง นวก.คอมพิวเตอร์ชำนาญการ เริ่มเรทที่ 0 บาทจนกว่าจะระบุ ข้อมูลเดิมที่มีรายชื่อรหัส 1–8 ตามลำดับจะเพิ่มคนที่ 9 ให้เมื่อเปิดโปรแกรมหรือนำเข้าไฟล์สำรอง โดยคงตารางและวันหยุดเดิมไว้

## ส่งออกตามแบบต้นฉบับ
- Excel ใช้โครงคำสั่ง รายชื่อ วันเวร หมายเหตุ และช่องลงนามจากตารางตัวอย่าง เปลี่ยนเดือน ปี พ.ศ. วันที่ วันในสัปดาห์ เวร และยอดรวมตามเดือนที่เปิดอยู่ รองรับรายชื่อได้ 9 คนตามแบบเดิม
- ระบุเลขที่คำสั่งและวันที่ออกคำสั่งที่ “สำรอง / พิมพ์ → ข้อมูลหัวเอกสารส่งออก” หากไม่ระบุจะเว้นไว้ให้เติม เก็บผู้ลงนามเดิมตามตัวอย่าง
- ไฟล์ Excel มีสูตรสรุปเวรและเงินแยกเรท พร้อมคอลัมน์ซ่อนเก็บรหัสเวร R/X และเรทสำหรับคำนวณ เงินจึงแยกสองประเภทได้แม้ในแบบพิมพ์ใช้ตัว ร เหมือนกัน พื้นที่พิมพ์และรูปแบบเดิมยังอยู่ ใช้ TH SarabunPSK ตามต้นฉบับ
- CSV เปิดภาษาไทยได้ด้วย UTF-8 BOM แยก R เป็น “ร” และ X เป็น “ร(รพ.สต.)” เพราะ CSV เก็บสีแยกสองประเภทนี้ไม่ได้
- หน้าเว็บฝัง Google Sans และ Noto Sans Thai ใช้ได้ออฟไลน์ ใบอนุญาตอยู่ใน css/GoogleSans-OFL.txt และ css/NotoSansThai-OFL.txt

## ตารางเริ่มต้น
เดือนตุลาคมเริ่มด้วยตารางว่างเช่นเดียวกับเดือนอื่น ไม่มีเวร OFF/VAC วันหยุดพิเศษ หรือกำหนดการ รพ.สต. จากตัวอย่างเดิม
หากเบราว์เซอร์ยังเก็บตัวอย่างเดือนตุลาคมชุดเดิมที่ไม่เคยแก้ไข แอปจะลบตัวอย่างให้โดยอัตโนมัติและย้อนกลับได้ ส่วนเดือนที่เคยแก้ไขจะเก็บไว้

## การบันทึก
ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ ไม่มีเซิร์ฟเวอร์หรือฐานข้อมูล
แต่ละโดเมน/พอร์ต/เบราว์เซอร์เก็บข้อมูลแยกกัน ไม่ซิงก์อัตโนมัติ
เมื่อแก้ js/data.js ข้อมูลเก่าที่เคยบันทึกไว้จะยังถูกใช้ก่อน
ควรสำรอง JSON ก่อนล้างข้อมูลเว็บไซต์ หากต้องการใช้ข้อมูลตั้งต้นชุดใหม่

## ทดสอบกติกา (ต้องมี Node.js)
เปิด Terminal ที่โฟลเดอร์นี้ แล้วรัน:
node tests/engine.test.cjs
node tests/painting.test.cjs
node tests/targets.test.cjs
node tests/exports.test.cjs
node tests/startup.test.cjs
node tests/monthly-total.test.cjs
node tests/rules-and-categories.test.cjs
node tests/month-staff-and-pay.test.cjs
node tests/outreach-chat.test.cjs

หลังแก้ HTML / CSS / JS ให้รวมไฟล์เดียวใหม่ด้วย `node scripts/build-standalone.cjs`

ทดสอบเวรเท่ากัน จำนวนคนครบ รักษา OFF/VAC และเวรที่ล็อก
รวมถึงห้ามบ่ายต่อดึก ข้ามเดือน และเดือนกุมภาพันธ์ 28/29 วัน
