# เว็บจัดเวรห้องบัตร

## คลังโค้ดรหัส (เพิ่มใหม่)
- ธีมคิตตี้สีชมพู พร้อมคิตตี้โบกมือและปุ่มพักแอนิเมชัน รูปฝังในไฟล์ Standalone ใช้ออฟไลน์ได้
- รวม Excel / สำรอง / นำเข้า ไว้ใน **จัดการข้อมูล** และรวมแก้ไข / ลบรหัสไว้ที่ **•••** ของแต่ละรายการ
- เอาปุ่มฐานข้อมูลออนไลน์ออกจากหน้าผู้ใช้แล้ว โมดูลเชื่อมต่อเดิมยังเรียกใช้ได้สำหรับผู้พัฒนา ดูรายละเอียดใน `ONLINE-DATABASE.md`
- เมนู **โค้ดรหัส**: เพิ่ม แก้ไข ลบ แบ่งหมวด A–Z พร้อมเลขรหัสและชื่อโรค
- เก็บเงื่อนไข หัตถการ และ Note แยกกันได้ ค้นหาได้ทุกช่องพร้อมตัวกรอง
- ส่งออก Excel `.xlsx` ทั้งคลังหรือเฉพาะผลค้นหา พร้อมสำรอง/รวม JSON แยกจากตารางเวร
- ใช้ออฟไลน์ได้ทันที เชื่อม Supabase ฟรีเพื่อส่ง/โหลดคลังข้ามเครื่องแบบกดเอง
- เริ่มเชื่อมออนไลน์ตาม [คู่มือฐานข้อมูลออนไลน์](ONLINE-DATABASE.md) และรัน [ไฟล์ SQL](supabase/code-library.sql)
- แก้ต้นฉบับใน `js/code-catalog.js`, `js/code-library.js`, `css/code-library.css` แล้วรัน `node scripts/build-standalone.cjs` เพื่ออัปเดตไฟล์เดียว

## เปิดใช้งาน
1. แตกไฟล์ ZIP ให้ครบทั้งโฟลเดอร์
2. ใน VS Code เลือก File > Open Folder แล้วเลือกโฟลเดอร์นี้
3. เปิด index.html ด้วย Chrome หรือใช้ Live Server ใน VS Code

ไม่ต้อง npm install และไม่ต้อง build ไฟล์ ไม่มีไลบรารีจากภายนอก

## ไฟล์ที่แก้ไขได้
- index.html: โครงสร้างหน้าเว็บ
- css/styles.css: สี ขนาดตัวอักษร การจัดวาง และรูปแบบตอนพิมพ์
- js/core.js: กติกาเวร ตัวตรวจเงื่อนไข และตัวจัดอัตโนมัติ
- js/data.js: รายชื่อและการตั้งค่าเริ่มต้น โดยทุกเดือนเริ่มด้วยตารางว่าง
- js/app.js: การคลิกตาราง หน้าต่างแก้ไข สรุปเวร บันทึกและส่งออก
- tests/engine.test.cjs: ตรวจเงื่อนไขของตัวจัดเวร
- ShiftPlanner-Standalone.html: เวอร์ชันรวมทุกอย่างในไฟล์เดียว เปิดได้ทันที

## วิธีใช้งาน
- เมนู “แชท” ใช้ลงวันออก รพ.สต.: กด “เลือกวันออก รพ.สต.” เลือกเดือน แล้วตอบ “วันที่เท่าไหร่บ้างคะ” เช่น `3, 5-6` ระบบเพิ่มเวร รพ.สต. วันที่ 3, 5, 6 วันละอย่างน้อย 1 คน พร้อมป้ายที่หัววันที่ และเปิดตารางเดือนนั้นให้ทันที
- แชททักทายว่า “สวัสดีค่ะ วันนี้มีอะไรให้ช่วยคะ” และมีปุ่ม “วันหน้าตู้KIOS (ร)” สำหรับเพิ่มวันเปิดเวร ร สีฟ้า โดยเลือกเดือนแล้วพิมพ์วัน เช่น `1, 7-8` ระบบเก็บวันเดิมและจำนวนคนที่ตั้งไว้แล้ว
- เลือกโหมด “ยกเลิกวัน” ในแชท แล้วเลือก รพ.สต. / หน้าตู้KIOS / OFF / Vac การยกเลิกเวรเลือกเดือนแล้วพิมพ์วัน เช่น `3, 5-6` จะปิดจำนวนที่เปิดไว้และลบเวรชนิดนั้นทุกคนในวันที่เลือก รวมช่องล็อกและข้อมูลคนที่ไม่ได้ลงตารางเดือนนี้ พร้อมแก้จำนวนที่จำไว้เพื่อไม่ให้กลับมาเมื่อจัดอัตโนมัติ ส่วน OFF/Vac จะถามคน → เดือน → วัน และล้างเฉพาะวันหยุดชนิดนั้นของคนที่เลือก
- ยกเลิกวันทั้งชุดแล้วย้อนกลับคืนได้ครั้งเดียวผ่านปุ่ม “ย้อนกลับ” ถ้าไม่มีรายการหรือยังไม่มีข้อมูลเดือนนั้นจะไม่สร้างข้อมูลใหม่ กด “ยกเลิกการกรอก” เพื่อหยุดรายการก่อนบันทึกได้ โดยไม่เปลี่ยนตาราง
- ปุ่ม “OFF” และ “Vac” ถามตามลำดับ บุคลากร → เดือน → วันที่ ระบบตรวจว่าคนนั้นลงตารางเดือนที่เลือกก่อนรับวันที่ แล้วบันทึกวันหยุดหรือ VAC เฉพาะคนที่เลือก โดยเปลี่ยนเวรในวันที่เลือกเป็นวันหยุด ย้อนกลับทั้งชุดได้ในครั้งเดียว
- แชทรองรับเลขไทย ช่วงวันที่ และชื่อเดือน เช่น `ออก รพ.สต. ๓, ๕–๖ พฤศจิกา` โดยชื่อเดือน/ปีต้องตรงกับเดือนที่เลือก วันที่เกินเดือนหรือรูปแบบผิดจะไม่แก้ข้อมูล วันออกเดิมและจำนวนที่ตั้งเกิน 1 คนยังเก็บไว้ กดจัดเวรอัตโนมัติเมื่อต้องการจัดบุคลากรลงเวร
- แชทบันทึกวันทั้งชุดเป็นการแก้ไขครั้งเดียว จึงย้อนกลับได้ในครั้งเดียว ปิดแชทก่อนส่งวันจะไม่แก้ตาราง มีปุ่ม “เริ่มคุยใหม่” และเก็บบทสนทนาระหว่างเปิด–ปิดแชทจนกว่าจะรีเฟรชหน้า
- แถบสีเหนือตาราง: เลือกชนิดเวรแล้วคลิกหรือลากวันที่ในแถวของคนเดียวกัน ปล่อยเมาส์เพื่อบันทึกทั้งชุด หากผิดเงื่อนไขจะไม่แก้ไขทั้งชุด
- คีย์ 1–5 = ดึก / เช้า / บ่าย / ห้องบัตร / รพ.สต. · 6 = OFF · 7 = VAC · 0 = ยางลบ
- ใช้ Tab เข้าตาราง แล้วใช้ลูกศรเลื่อนช่อง; Shift + ลูกศรซ้าย/ขวาเลือกหลายวัน; Enter หรือ Space ใส่เวรที่เลือก; Delete ลบ; E เปิดรายละเอียด/ปลดล็อก
- Ctrl+Z (Mac: Cmd+Z) ย้อนทั้งชุดที่ลาก · Esc ยกเลิกก่อนบันทึก · คีย์ลัดหยุดทำงานในช่องกรอกข้อมูลและหน้าต่างแก้ไข
- บนจอสัมผัส: เลือกเวรก่อนลากเพื่อระบาย เปลี่ยนเป็นโหมด “ดู / แก้รายช่อง” เมื่อต้องการเลื่อนตาราง
- ปุ่ม “สร้างเอกสาร” ข้างปฏิทินรวม Excel ตามต้นฉบับ, CSV, พิมพ์/PDF, สำรอง JSON และนำเข้าไฟล์ไว้ในที่เดียว โดย Excel เก็บสี เส้นตาราง ฟอนต์ และเซลล์รวม ส่วน CSV เก็บเฉพาะข้อมูล
- เลือกเดือนแล้วเปิด “บุคลากร” ติ๊ก “ลงตารางเดือนนี้” เพื่อเลือกผู้ร่วมตาราง คนที่ไม่เลือกจะไม่แสดงในตาราง สรุปเงิน การจัดอัตโนมัติ และเอกสารของเดือนนั้น ข้อมูลเวรและเป้าเดิมยังเก็บไว้เมื่อเลือกกลับมา และไม่กระทบการเลือกของเดือนอื่น
- คลิกช่องบุคลากร/วันที่ เพื่อเลือกเวร OFF หรือ VAC
- เมื่อเลือกเวรเองและล็อกไว้ (◆) ระบบจะรักษาเฉพาะช่องนั้น และจัดช่องว่างวันอื่นของคนเดียวกันต่อได้ โดยคง OFF / VAC และเงื่อนไขเวรทั้งหมด
- ปลดล็อกเฉพาะเวรที่ต้องการให้ระบบจัดใหม่ได้ กรอกเป้าห้องบัตร / รุ่งอรุณเมื่อต้องการกำหนดจำนวนต่อคน ระบบไม่กันทั้งคนออกเพียงเพราะมีเวรล็อกอยู่วันอื่น
- คลิกหัววันที่เพื่อกำหนดวันหยุดราชการและจำนวนคนของแต่ละเวร
- เลือกเดือนใหม่เพื่อเริ่มตารางว่าง เพิ่มวันหยุดราชการเอง
- กดจัดเวรอัตโนมัติ แล้วตรวจให้แสดงว่าผ่านทุกเงื่อนไขก่อนนำไปใช้
- ส่งออก CSV เพื่อเปิดใน Excel หรือพิมพ์/บันทึกเป็น PDF
- สำรอง JSON เพื่อย้ายเครื่องหรือเก็บข้อมูลไว้แก้ไขต่อ

## กติกาเริ่มต้น
- ร สีฟ้า หน้าตู้KIOS: 06:30–08:30 ทุก จ.–ศ. วันละ 1 คน รวมวันที่ตรงวันหยุดราชการ ปรับได้ที่หัววันที่
- ร สีแดง รพ.สต.: 06:30–08:30 กำหนดจำนวนตามวันที่ออก
- วันหยุดและเสาร์–อาทิตย์: ดึก 1 เช้า 2 บ่าย 1 คน
- วันธรรมดา: ดึก 1 บ่าย 1 รวม 2 เวรต่อวัน วันเสาร์–อาทิตย์และวันหยุดพิเศษ: เช้า 2 บ่าย 1 ดึก 1 รวม 4 เวรต่อวัน ระบบคำนวณจำนวนห้องบัตรตามปฏิทิน ไม่ต้องกำหนดทีละวัน วันหยุดพิเศษที่ตรงเสาร์–อาทิตย์ไม่นับซ้ำ
- ดึก 00:00–08:00 / เช้า 08:00–16:00 / บ่าย 16:00–00:00
- ทุกคนมีเป้ารายบุคคล ไม่มีข้อบังคับให้ลำดับ 2–4 เท่ากัน ทั้งห้องบัตร รุ่งอรุณ และยอดรวม เมื่อมี OFF/VAC มาก ระบบจัดเวรห้องบัตรที่เหลือให้ผู้ที่ว่าง โดยยังรักษาเป้าที่กรอกเอง
- ในการจัดอัตโนมัติ นวก. มีห้องบัตร + รุ่งอรุณรวมกันไม่เกินตัวหลักที่ได้เวรน้อยที่สุด (ลำดับ 1–4 ที่ยังรับเวรและลงตารางเดือนนั้น) รพีพรรณเป็นกลุ่มรองจากตัวหลัก เวรห้องบัตรส่วนเพิ่มให้ตัวหลักก่อน หากเป้าที่กรอกขัดกัน ระบบแจ้งสาเหตุและเก็บตารางเดิมไว้
- แก้ช่อง “รวม” หลังจัดแล้วเพื่อกำหนดจำนวนเวรทั้งหมดของคนนั้น ระบบลองย้ายเวรในตารางเดิมก่อนค้นหาตารางใหม่ โดยรักษาช่องล็อก OFF / Vac และตรวจทุกเงื่อนไขอีกครั้งก่อนบันทึก
- กดข้อความใต้ “รุ่งอรุณ” ที่ Header เพื่อดูจำนวนเวรหน้าตู้KIOS + รพ.สต. ที่เปิด ค่าเฉลี่ยต่อผู้รับเวร และตารางสัดส่วนแนะนำรายคน ค่าเฉลี่ยเป็นจุดเริ่มต้น ผลจริงอาจต่างตามสิทธิ์รับเวร วันว่าง เป้า และข้อจำกัดรายวัน
- กันวัน OFF และ VAC ออกจากการจัดอัตโนมัติ
- หนึ่งคนรับเวรได้วันละหนึ่งประเภท และห้ามบ่ายแล้วต่อดึก รุ่งอรุณห้องบัตร หรือ รพ.สต. ในวันถัดไป
- ห้องบัตร ด / ช / บ รวมกันห้ามติดกันเกิน 2 วัน แม้สลับชนิดเวร ร สีฟ้าและสีแดงไม่นับในช่วงนี้ วันที่ว่าง OFF / Vac หรือรุ่งอรุณจะตัดช่วงห้องบัตร ตรวจสองวันปลายเดือนก่อนและสองวันต้นเดือนถัดไปด้วยหากมีข้อมูล ใช้กับการลาก แก้รายช่อง และจัดอัตโนมัติ
- ตารางเดิมยังเก็บไว้ หากมีห้องบัตรล็อกติดกัน 3 วัน ระบบแจ้งให้แก้หรือปลดล็อกบางช่อง เป้าที่เกินจำนวนวันว่างและกติกาห้องบัตร 2 วันติดกันจะแจ้งจำนวนสูงสุดที่รับได้ ข้อห้ามบ่ายต่อดึก / ร ทั้งสองสียังคงใช้แยกต่างหาก
- เวรดึกทุกวัน รวมวันธรรมดาและวันหยุด รับได้ทุกคนที่เปิดสิทธิ์ N และยังรับเวรอยู่ ยกเว้นปรเมศวร์ (id 9) ที่รับได้เฉพาะ X / ช่องว่าง
- ตรวจบ่ายต่อดึกและบ่ายต่อ ร ทั้งสองสีข้ามเดือนจากตารางเดือนข้างเคียงที่มีอยู่โดยอัตโนมัติ ไม่ต้องกรอกเวรก่อน/หลังเดือนในเมนูบุคลากร
- การเลือกเวรเองเป็นฉบับร่างได้ แอปเตือนกำลังคน สิทธิ์รับเวร วันลา และเป้ารายคนจนกว่าจะแก้ครบ
- ถ้าจัดไม่ได้ ระบบเก็บข้อมูลเดิมและแจ้งสาเหตุ

## เป้าหมายเวรและค่าเวร
- หลังจัดอัตโนมัติแล้ว แก้เลขห้องบัตรหรือรุ่งอรุณของคนใดก็ได้และกดจัดใหม่ ระบบอ่านค่าที่เพิ่งพิมพ์แม้ยังไม่ได้ออกจากช่อง แล้วคำนวณตารางใหม่จากเป้ารายคนทั้งหมด โดยคงเวรล็อกและ OFF/VAC ช่องอัตโนมัติเดิมจะจัดใหม่ได้ เป้ารุ่งอรุณนับ R + X เช่น กรอก 3 ต้องได้รวมสองสี 3 เวร
- เป้าที่กรอกเองมีลำดับก่อนส่วนแบ่งอัตโนมัติ ระบบจัดสรรยอด R/X ร่วมกัน แล้วกระจายส่วนที่เหลือให้คนอื่น เช่น นายปรเมศวร์ตั้งรุ่งอรุณ 3 จะจอง X ให้ 3 เวรก่อน และลดการแจก X คนอื่นตามจำนวนที่เหลือ หากวันเปิดเวร วันลา เวรล็อก หรือยอดเป้ารวมทำให้จัดไม่ได้ จะแจ้งข้อจำกัดและจำนวนที่รองรับโดยไม่เปลี่ยนตารางบางส่วน
- ตารางเวรและหน้าสรุปมีคอลัมน์ ห้องบัตร (N/M/A), รุ่งอรุณ (R สีฟ้า หน้าตู้KIOS + X สีแดง รพ.สต.) และ รวม เมื่อยังไม่ตั้งเป้า ช่องจะแสดงจำนวนที่ลงจริงทันทีเมื่อเพิ่มหรือลบเวร โดยไม่บันทึกจำนวนนั้นเป็นเป้า
- พิมพ์ตัวเลขเพื่อกำหนดเป้าสำหรับจัดอัตโนมัติ ไม่มีข้อความ ขาด / เกิน / ครบ ใต้ช่อง ล้างเลขเพื่อกลับมานับจากตารางและให้ระบบคำนวณส่วนที่เหลือ
- ช่อง “รวม” พิมพ์เป้าเวรรวมต่อคนได้ทั้งในตารางและหน้าสรุป เมื่อกรอกจะใช้ยอดนั้นแทนเป้าแยกห้องบัตร/รุ่งอรุณของคนเดียวกัน แล้วให้ระบบแบ่งประเภทใหม่เมื่อกดจัดอัตโนมัติ คนอื่นไม่เปลี่ยนเป้า กรอก 0 เพื่องดเวรทั้งหมด ล้างช่องเพื่อกลับมาบวกห้องบัตร + รุ่งอรุณอัตโนมัติ ตัวเลขและข้อความขาด/เกินซิงก์สองหน้า และอ่านค่าที่กำลังพิมพ์ก่อนจัดได้
- เป้าห้องบัตรและรุ่งอรุณรวมกันต้องไม่เกินจำนวนวันของเดือน ทุกช่องแก้แยกบุคคลได้ การพิมพ์หรือล้างคนหนึ่งไม่เปลี่ยนเลขของคนอื่น ทั้งในตารางและหน้าสรุป
- เป้ารุ่งอรุณและ รพ.สต. จากข้อมูลเดิมจะนำมาบวกเป็นเป้ารุ่งอรุณเดียวกัน ระบบจัดอัตโนมัตินับ R และ X ร่วมกันตามเป้านี้ โดยยังเลือกวันและสถานที่ออกเวรได้ตามเดิม และใช้เรทรุ่งอรุณเดียวกันในการคำนวณ
- ไฟล์สำรองเก่าที่ยังมีเป้ารวมช่องเดียวจะเก็บเป้าเดิมไว้จนกว่าจะเริ่มแก้เป้าแยกประเภท จัดอัตโนมัติสำเร็จแล้วช่องที่ไม่ได้ตั้งเป้าจะยังนับตามเวรจริง
- เมนูหลักอยู่ใน Header ด้านบนและตรึงไว้ตลอดเมื่อเลื่อนหน้า ทั้งบนคอมพิวเตอร์และมือถือ
- ยอดรวมที่กรอก ห้องบัตร / รุ่งอรุณ อยู่ในแถบสีอ่อนใต้เมนู พร้อมชื่อเดือนที่เลือก ตรึงอยู่ด้านบนทั้งเมื่อเลื่อนหน้าและเลื่อนตาราง ตัวเลขอัปเดตทันทีขณะพิมพ์ ไม่มีช่องยอดรวมท้ายตารางเวร
- Header แสดง “เวรทั้งหมด” เป็นยอดห้องบัตรจากปฏิทิน “ลงแล้ว” สีเขียวเป็นจำนวนห้องบัตรที่ลงจริง และ “รุ่งอรุณ” แสดงแยกต่างหาก กดสูตรใต้เวรทั้งหมดเพื่อดูวันธรรมดา × 2 + วันหยุด × 4 และจำนวนรุ่งอรุณที่เพิ่มจากห้องบัตร
- ยอดห้องบัตรประจำเดือนยึดตามปฏิทิน แม้กรอกเป้าครบทุกคนแล้วก็ไม่ลดจำนวนเวรรายวันให้เท่ายอดที่กรอก หากกรอกรวมไม่ตรง ระบบแสดงสูตรแยกห้องบัตร / หน้าตู้KIOS / รพ.สต. และแนะนำให้ปรับยอดหรือล้างเป้าบางคนเพื่อให้กระจายส่วนที่เหลือ
- ปุ่มจัดเวรอัตโนมัติอยู่ในหัวตารางข้าง “ล้างเวร” ช่องที่ไม่ได้ตั้งเป้าจะแสดงจำนวนที่จัดได้หลังจัดสำเร็จ และอัปเดตเมื่อแก้ตารางต่อ
- ระบบคำนวณจำนวนห้องบัตรใหม่จากเดือนและวันหยุดก่อนจัดทุกครั้ง โดยคง OFF/Vac และเวรล็อก ข้อมูลเก่าที่เคยลดจำนวนรายวันหรือเก็บ autoCapacity จะเปลี่ยนมาใช้สูตรปฏิทิน รุ่งอรุณที่เปิดไว้ยังอยู่ และวัน รพ.สต. / หน้าตู้KIOS ที่ลงเองจะถูกนับเป็นวันที่เปิดเวรด้วย
- นับ N / M / A / R / X เป็นครั้งละหนึ่งเวร ไม่รวม OFF / VAC หากลงเองไม่ครบหรือเกินเป้าจะแสดงเตือน ระบบเติมช่องว่างให้คนที่มีเวรล็อกได้ทั้งเมื่อมีเป้าและเมื่อนับอัตโนมัติ
- พฤกษา (id 1) กับรพีพรรณ (id 8) ร่วมวันเดียวกันได้เมื่ออยู่คนละกะ ห้ามอยู่กะเดียวกันในวันเดียวกัน ทั้งการจัดเองและอัตโนมัติ R สีฟ้ากับ X สีแดงถือเป็นกะรุ่งอรุณเดียวกันเพราะเวลาเดียวกัน
- รุ่งอรุณจัดตามปกติ: รพ.สต. (X) ให้ทุกคนอย่างน้อย 1 เมื่อเวรและวันว่างพอ หากไม่พอให้ตัวหลักลำดับ 1–4 ก่อน แล้วจึงคนอื่น หน้าตู้KIOS (R) เริ่มจากหารเฉลี่ยตามผู้รับ R ได้ ไม่รวมนายปรเมศวร์ แจกเศษให้ตัวหลักก่อน และปรับตามวันว่างหรือเป้ารายคนได้ ไม่มีการถัวรุ่งอรุณเฉพาะลำดับ 2–4 ยอดคอลัมน์รุ่งอรุณยังเป็น R + X
- เมนูบุคลากรมีเรทเพียง 2 ช่องต่อคน: ห้องบัตร (N/M/A) และ รุ่งอรุณ (R สีฟ้า + X สีแดง) เรทรุ่งอรุณใช้ร่วมกันทั้งหน้าตู้KIOS และ รพ.สต. ค่าเริ่มต้นตามตำแหน่ง จพ.เวช 60 บาท, พนักงาน 50 บาท, นวก. 80 บาทต่อเวร ทุกช่องแก้เองได้ ทศนิยมไม่เกิน 2 ตำแหน่ง และใช้กับทุกเดือน ยอดเงิน = (N+M+A) × เรทห้องบัตร + (R+X) × เรทรุ่งอรุณ
- ข้อมูลเก่าที่เก็บเรทเลขเดียวจะรักษาเป็นเรทห้องบัตร และตั้งรุ่งอรุณตามตำแหน่ง ถ้าแบบเดิมคัดลอกเรทห้องบัตรใส่ทั้งสองช่องรุ่งอรุณ จะเปลี่ยนเป็นค่าเริ่มต้นตามตำแหน่ง ถ้ามีเรทที่ปรับเองจะใช้ค่านั้นร่วมกันสองสี กรณีทั้งสองช่องเคยปรับต่างกัน ใช้ช่องรุ่งอรุณเดิมเป็นหลัก หลังแปลงเก็บเพียง {card,dawn} และไม่เปลี่ยนตารางเวร
- บุคลากรลำดับ 9 นายปรเมศวร์ ศิริเสาร์ ตำแหน่ง นวก.คอมพิวเตอร์ชำนาญการ เริ่มเรทที่ 0 บาทจนกว่าจะระบุ ข้อมูลเดิมที่มีรายชื่อรหัส 1–8 ตามลำดับจะเพิ่มคนที่ 9 ให้เมื่อเปิดโปรแกรมหรือนำเข้าไฟล์สำรอง โดยคงตารางและวันหยุดเดิมไว้

## ส่งออกตามแบบต้นฉบับ
- Excel ใช้โครงคำสั่ง รายชื่อ วันเวร หมายเหตุ และช่องลงนามจากตารางตัวอย่าง เปลี่ยนเดือน ปี พ.ศ. วันที่ วันในสัปดาห์ เวร และยอดรวมตามเดือนที่เปิดอยู่ รองรับรายชื่อได้ 9 คนตามแบบเดิม
- ระบุเลขที่คำสั่งและวันที่ออกคำสั่งที่ “สำรอง / พิมพ์ → ข้อมูลหัวเอกสารส่งออก” หากไม่ระบุจะเว้นไว้ให้เติม เก็บผู้ลงนามเดิมตามตัวอย่าง
- ไฟล์ Excel มีสูตรสรุปเวรและเงินแยกเรท พร้อมคอลัมน์ซ่อนเก็บรหัสเวร R/X และเรทสำหรับคำนวณ เงินจึงแยกสองประเภทได้แม้ในแบบพิมพ์ใช้ตัว ร เหมือนกัน พื้นที่พิมพ์และรูปแบบเดิมยังอยู่ ใช้ TH SarabunPSK ตามต้นฉบับ
- CSV เปิดภาษาไทยได้ด้วย UTF-8 BOM แยก R เป็น “ร” และ X เป็น “ร(รพ.สต.)” เพราะ CSV เก็บสีแยกสองประเภทนี้ไม่ได้
- หน้าเว็บฝัง Google Sans และ Noto Sans Thai ใช้ได้ออฟไลน์ ใบอนุญาตอยู่ใน css/GoogleSans-OFL.txt และ css/NotoSansThai-OFL.txt

## ตารางเริ่มต้น
เดือนตุลาคมเริ่มด้วยตารางว่างเช่นเดียวกับเดือนอื่น ไม่มีเวร OFF/VAC วันหยุดพิเศษ หรือกำหนดการ รพ.สต. จากตัวอย่างเดิม
หากเบราว์เซอร์ยังเก็บตัวอย่างเดือนตุลาคมชุดเดิมที่ไม่เคยแก้ไข แอปจะลบตัวอย่างให้โดยอัตโนมัติและย้อนกลับได้ ส่วนเดือนที่เคยแก้ไขจะเก็บไว้

## การบันทึก
ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ ไม่มีเซิร์ฟเวอร์หรือฐานข้อมูล
แต่ละโดเมน/พอร์ต/เบราว์เซอร์เก็บข้อมูลแยกกัน ไม่ซิงก์อัตโนมัติ
เมื่อแก้ js/data.js ข้อมูลเก่าที่เคยบันทึกไว้จะยังถูกใช้ก่อน
ควรสำรอง JSON ก่อนล้างข้อมูลเว็บไซต์ หากต้องการใช้ข้อมูลตั้งต้นชุดใหม่
